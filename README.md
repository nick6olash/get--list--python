get--list--v1.py 

-is a beginner-friendly interactive Python project that:

Uses pyfiglet to display stylized text.
Greets the user and asks for their name.
Stores a list containing a Minecraft entry with its platform and release year.
Asks whether the user wants to view the list.
Prints the list if the user enters yes.
The project demonstrates basic concepts such as imports, variables, input/output, dictionaries, lists, and conditional statements.
